# Project One: Operating System Recommendation

Project One evaluated an enterprise operating system for a fictional financial-technology company, GlobalFinTech Inc.

I recommended **Red Hat Enterprise Linux (RHEL)** and evaluated it across the areas that mattered most to the scenario:

- Security and access control
- Stability and reliability
- Integrity, confidentiality, and availability
- Operating-system architecture
- CPU, memory, and I/O resource management
- Failure metrics and dependability
- Distributed environments and high availability
- Performance monitoring
- Overall business appropriateness

The project gave me practice translating operating-system concepts into a business recommendation instead of evaluating technology only by specifications. It also reinforced the importance of connecting security, performance, reliability, supportability, and implementation complexity to the actual environment being supported.
